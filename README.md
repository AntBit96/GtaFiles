## What is this?

To give it a home with some personality, this repo imagines what an open-world crime game's
economy would look like if DacityCoin were the street currency. The main file reads like a
real game data table, with sections, keys, IDs and localization strings, but everything in it
is written from scratch and is fictional.

| `README.md` | This page. |

## What's inside `vice_economy_data.txt`

- **Currency definitions:** DacityCoin (`$A`) as the primary currency, plus a "Legacy Cash" fallback.
- **Exchange rules and ATM network:** in-world conversion of old cash into $A.
- **Vendors:** weapons, apparel, food and car tuning, all priced in $A.
- **Vehicles and properties:** dealers, safehouses, businesses and daily $A income.
- **Mission rewards:** story, side and heist payouts in $A.
- **Activities, wanted-level fines and achievements**.
- **Phone apps:** the "A-Wallet" app and a fictional "Vice Ticker" market listing `$A`.
- **Radio ads, billboards and localization strings** that mention DacityCoin.
- **Changelog** in a typical game-file format.
